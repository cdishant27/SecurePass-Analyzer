# SecurePass Analyzer (CAP790 CA3)

## Setup
    pip install -r requirements.txt
    python app.py
Open http://127.0.0.1:5000 (internet needed for the breach check).

## Files
- app.py              Flask backend: entropy, zxcvbn analysis, crack time, k-anonymity breach check, hash demo, generator
- templates/index.html  Frontend
